## 자주 찾는 것

**"홈 화면을 고치고 싶다"** → `screens/PostList.jsx` + `styles/home.css`

**"매물 카드 모양을 바꾸고 싶다"** → `components/PostCard.jsx` (다섯 화면이 함께 씀)

**"관리자 신고 화면을 고치고 싶다"** → `admin/ReportsPage.jsx`

**"색을 바꾸고 싶다"** → `styles/base.css` 의 변수

**"서버 주소를 바꾸고 싶다"** → `api.js` 또는 `.env` 의 `VITE_API_URL`
