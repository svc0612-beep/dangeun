## 8. 파일이 아닌 것

| 이름 | 무엇 |
|---|---|
| `agents/` | 에이전트 지시서 `.md` 10개 |

| `scripts/` | 위 6번의 따로 실행하는 파일들 |

| `__pycache__/` | 파이썬이 만든 임시 파일. 지워도 다시 생김 |
| `danggeun.db` | **DB 파일.** 이 하나에 모든 자료가 들어 있음 |
| `learned_tips.json` | 채팅 자동완성이 배운 문구 |

## 자주 찾는 것

**"사기 기준을 고치고 싶다"** → `risk_score.py` 의 `RULES`

**"에이전트가 하는 말을 바꾸고 싶다"** → `agents/` 폴더의 `.md`

**"택배 관련 금지어를 늘리고 싶다"** → `badwords.py` 의 `SCAMS`

**"같은말 사전을 늘리고 싶다"** → `config.py` 의 `SYNONYM_GROUPS`

**"새 API 를 만들고 싶다"** → `routers/` 안에서 알맞은 파일

**"DB 에 칸을 늘리고 싶다"** → `database.py` 고치고 `python database.py`
